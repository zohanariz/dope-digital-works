# Zohan Solutions landing page

A premium, responsive Next.js 14 + TypeScript landing page based on the supplied one-page PDF. The visual direction is editorial and restrained: deep charcoal, warm off-white type, muted green accents, fine rules, strong typography, and a custom CSS systems illustration instead of generic stock-style AI imagery.

## Run locally
1. Install Node.js 18.17 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Before launch
- In `components/LandingPage.tsx`, replace `https://calendly.com/` with the client's actual Calendly URL.
- The calendar area is deliberately a placeholder until the actual booking URL or embed is supplied.
- The FAQ answers are intentionally non-specific because the supplied PDF lists the questions but does not provide written answers.
- Check all content and legal/privacy requirements with the client before publishing.

## Content fidelity
The copy and section structure follow the provided Zohan Solutions PDF. Minor punctuation and line-break normalization were applied for web readability. No invented client testimonials or performance statistics have been added.
